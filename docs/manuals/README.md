# PredictFix 示範維修手冊資料集

本資料集包含四份原創、完整結構的虛構設備維修手冊，供檢索、問答、引用與資料不足測試。它們不是任何廠商的原廠文件，不得用於真實設備維修或判定復機。

虛構品牌：青岳精機 DEMO；虛構機型：PF-VMC850-DEMO；虛構控制器：PF-Control-D。現有 CNC-01～18 沒有自動取得此機型適用性，不能把示例規格當成它們的原廠規格。

| 文件 | 範圍 | 版本 |
|---|---|---|
| [主軸與潤滑](PF-MAN-SPINDLE-001.md) | 主軸異音、振動、溫升、潤滑與驗收 | 1.0 |
| [自動換刀機構](PF-MAN-ATC-002.md) | 換刀卡住、位置訊號、刀具資料與恢復確認 | 1.0 |
| [冷卻循環系統](PF-MAN-COOLANT-003.md) | 流量下降、溫升、過濾、洩漏與維護 | 1.0 |
| [進給與定位](PF-MAN-FEED-004.md) | 尺寸漂移、反向誤差、伺服警報與量測 | 1.0 |

每份文件包括適用範圍、組件、巡檢、症狀矩陣、排查順序、停止與升級條件、備品、驗收、案例與紀錄表。所有案例為合成資料；案例中的原因只在該情境成立。警報使用 DEMO 命名空間；數值僅為示例量測，不是允許值、設定值或通用門檻。

`manifest.json` 是文件來源與適用範圍的唯一索引。後端以章節分段載入，保留文件版本、章節、來源路徑、行號與虛構標記。Markdown 沒有固定頁碼，因此不虛構 PDF 頁碼。
