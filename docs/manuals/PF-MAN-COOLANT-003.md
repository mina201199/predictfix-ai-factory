# PF-VMC850-DEMO 冷卻循環系統維修手冊

> 虛構示範文件｜非原廠手冊｜冷卻介質、壓力、流量、濃度與溫度標準須查真實機型及介質供應商。本文數值只表示合成案例的觀察。

## 01 文件管制與適用範圍

文件編號 PF-MAN-COOLANT-003；版本 1.0；發布日 2026-10-05；虛構品牌青岳精機 DEMO；虛構機型 PF-VMC850-DEMO；控制器 PF-Control-D。本冊涵蓋一般冷卻液儲槽、泵、過濾與管路的通報、巡檢及證據整理。

不涵蓋真實高壓穿心系統設計、泵拆裝、電氣維修與介質調配比例。主軸冷卻支路與加工冷卻是否共用，必須依配置確認；名稱相近不代表同一系統。相關主軸溫升問題另參 PF-MAN-SPINDLE-001。

## 02 角色與作業前提

操作人員留下液位、警報、流量觀察、洩漏與加工變更。維修人員依資格確認管路、過濾及供應線索；需要接觸介質、排放或清理時依廠內化學品、污染與隔離程序。電氣、泵拆装及高壓作業需合格人員與適用程序。

不得在壓力未確認的狀態拆接頭，不向泵加入未知介質，不徒手探查運轉泵，也不憑液體顏色判定成分。洩漏涉及滑倒、介質暴露或電氣區域時，按現場制度處理與升級。廢液依廠內規範管理。

## 03 系統構成與資料鏈

| 示範節點 | 功能 | 可追溯資料 |
|---|---|---|
| TK-01 儲槽 | 保存介質及回流 | 液位、補充、介質批號 |
| FL-01 過濾段 | 管理顆粒與切屑 | 清潔、更換及異常紀錄 |
| PM-01 冷卻泵 | 循環供應 | 啟停、負載與服務紀錄 |
| LN-01 供應管路 | 將介質送至使用端 | 測點、閥位確認、洩漏位置 |
| RT-01 回流段 | 回收加工介質 | 回流、阻塞與環境觀察 |

流量須有單位、測點與條件；看見噴流變小可作症狀描述，但不是量測值。電流與流量的關係依泵與工況判斷，不能以單一電流直接確認堵塞或剩餘壽命。

## 04 受理欄位與必要追問

受理欄位包括設備、系統名稱、開始時間、持續或間歇、完整警報、液位、流量或噴流觀察、加工材質、最近清理與補液、管路變更、環境溫度、洩漏位置。

先追問「只有一個使用端變小，還是多個使用端都變小」「泵運轉狀態如何」「是否只有切削時過熱」「補液或更換介質後是否發生」。沒有儀表時填觀察及未知，不生成假的 L/min 或 bar。

## 05 日常保養與紀錄矩陣

以下為示範維護分類，實際頻率及方法須依核准保養計畫。

| 時機 | 查核項目 | 保存資料 |
|---|---|---|
| 班前 | 液位、洩漏、既有警報 | 值或觀察、時間、人員 |
| 當班 | 噴流、回流、加工與溫升變化 | 發生條件與位置 |
| 計畫清潔 | 儲槽、過濾段與切屑管理 | 清潔範圍、廢液與耗材 |
| 補液後 | 介質名稱、批號及核准調配紀錄 | 禁止把未知油品混入 |
| 維修後 | 同條件供應及洩漏確認 | 前後量測與驗收來源 |

介質濃度、pH、微生物與相容性如有管理需求，使用核准方法與供應商規格，不能用本册猜通用濃度或化學添加量。

## 06 故障排查矩陣

| 症狀 | 可能方向 | 證據需求 | 不可直接推定 |
|---|---|---|---|
| 多個使用端流量下降 | 液位、過濾、供應與回流 | 同條件量測、液位及維護紀錄 | 一定要換泵 |
| 單一使用端流量下降 | 支路、接頭與使用端線索 | 各支路對照、近期變更 | 整套系統故障 |
| 液位下降伴隨洩漏 | 管路、密封、回收與補充 | 洩漏位置、時間與量 | 單憑顏色可辨介質 |
| 泵有異音但流量未量測 | 液位、供應、機械或電氣線索 | 音源、運轉條件、服務紀錄 | 異音就是軸承壞 |
| 加工溫升且供應看似正常 | 測點、負載、介質與加工條件 | 實際流量、工具及製程紀錄 | 冷卻系统一定沒問題 |
| 補液後泡沫或品質異常 | 介質、調配、污染與回流 | 批號、補充紀錄與核准規範 | 自行加藥即可改善 |

## 07 分支查核流程

第一步確認是加工冷卻、主軸冷卻還是其他支路；第二步保存液位、警報、流量和變更資料；第三步由合格人員在核准條件下比較不同使用端與供應紀錄。必要時轉交電氣、泵或介質專業人員。

如果多個使用端同時下降，保留共通供應、過濾與回流的查核方向；若只有單支路異常，整理局部支路證據；若沒有量測，先標記「流量下降為觀察」，不要寫成已確認的泵性能衰退。

處置前後保持可比較條件。測點、閥位、負載或介質改變時，註明差異。檢查與處置由人工確認，助手只整理所需資訊與文件。

## 10 復測與驗收表

驗收前約定使用端、量測方式、泵與支路狀態、介質、負載及環境。依真實機型文件確認供應、洩漏與加工結果。觀察正常但沒有量測或規格時，標记驗證範圍，不宣告所有性能合格。

| 欄位 | 填寫要求 |
|---|---|
| 前後流量 | 單位、測點、工具與條件 |
| 溫度 | 位置、時間與環境 |
| 管路／洩漏 | 位置與處理前後照片 |
| 介質 | 名稱、批號與核准規範 |
| 實際措施 | 清潔、修復或更換的具體範圍 |
| 審核 | 驗收文件、確認人與追蹤日期 |

## 11 合成案例與對照

案例 CL-A：多支路供應觀察下降；合成同條件讀值為 18 L/min 到 11 L/min，清理經確認的過濾段後讀值為 17 L/min。這些數字不構成真實泵規格，17 L/min 不代表通用合格。案例中原因由查核紀錄確認，不能僅因流量上升就泛化为所有泵故障。

案例 CL-B：只有一個使用端噴流變小，共通供應資料未見同樣變化。情境設定為局部支路問題，工程師核對現場資料後處理；沒有更換泵。這是避免助手看見「流量小」就一律推薦换泵的反例。

案例 CL-C：補液後品質改變但缺批號與調配紀錄，原因未知。適當回答是補資料、查供應商規範與專業人員，不編造比例。

## 12 交接與常見問答

交接欄位：系統名稱；設備／機型；症狀；液位；測點／流量／溫度；介質；補充與保養紀錄；洩漏照片；查核；原因狀態；措施；備品；驗收；未知事項；接手人與審核。

問：液位正常能排除供應問題嗎？答：不能，還需要流量、支路、過濾及工況等證據。

問：低流量可以直接推估故障風險嗎？答：本資料集沒有經驗證的風險模型，只能提供查核方向。

問：AI 能自動決定補液比例與更換泵嗎？答：不能以本冊作此決策，須確認核准規格與實際證據。
