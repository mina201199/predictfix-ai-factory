# 單一工廠設備模板

2026-10-08：本輪維持一個工廠與現有 CNC 展示，未新增其他工廠、輸送帶展示或 OpenAI API 呼叫。

## 操作

主管登入後，在設備總覽點「新增機台」，或到維修管理的設備建檔頁。
選擇設備模板即可預覽零件、量測與排查／驗收項目。「管理設備模板」可另存內建模板副本，修改後保存。

內建兩種結構模板：CNC 加工中心、CNC 車床。自訂模板可設定名稱、設備類別、示意外觀、1–16 個零件、0–6 個量測欄位，以及2–16個排查／驗收項目。
量測指標目前限定溫度、振動、電流、壓力、轉速、偏差，單位固定；可自訂欄位名稱。沒有自動感測或自動判定健康度。

新增設備需填編號、名稱與實際機型。設備保存模板完整快照與版本，健康度和量測數值為未知。模板更新只影響之後新增設備，不覆寫既有設備或工單。

到「維修流程」選擇該設備的工單，在主管編排排查／驗收清單時，系統會以設備模板項目作為初稿。若選定手冊來源，優先以該來源編排。
主管須確認適用機型與判定依據，核准後既有逐項結果、驗收阻擋、重修與審核流程才生效。模板本身不是原廠程序，也不自動核准工單。

提交證據時顯示模板建議量測欄位；必要量測仍依核准清單確認，不把空白欄位當成通過。

## API 與資料

- `GET /api/equipment-templates`：登入人員讀取模板。
- `POST /api/equipment-templates`：主管建立副本。
- `PUT /api/equipment-templates/{id}`：主管修改，須附目前 revision；過期版本回傳409。
- `POST /api/machines`：可附 template_id；未指定時使用相對應內建結構，不再複製資料庫第一台設備。
- 新增 `equipment_templates` 資料表，設備 payload 保存 equipment_template 與 measurement_fields。

沒有修改現有設備資料或既有工單規則。單一工廠原型仍不具備多租戶隔離。

## 驗證與部署

隔離資料庫測試：零件重複／空白、缺少驗收、示意類型衝突、主管權限、過期版本、既有設備快照、未驗收提交阻擋。
瀏覽器檢查：主頁與管理頁模板預覽、副本建立與編輯、五零件設備建立、手機版與工單不變。UI 驗證設備已停用，展示模板副本保留供體驗。
本輪更新部署至本機8094，部署前使用SQLite backup工具保存原資料庫；不是公開網站或企業正式上線。
